# Contribuer

Merci de contribuer à Pokémon Fangame Translator.

## Avant de proposer une modification

1. Travaillez sur une branche dédiée.
2. Ne joignez aucun fangame, fichier `.rxdata`, banque de messages, dialogue extrait, musique ou graphisme protégé.
3. Utilisez uniquement des données de test inventées ou créées pour le projet.
4. Compilez les fichiers Python avec `python -m py_compile`.
5. Testez l'analyse, l'extraction, la traduction et la reconstruction sur une copie.

## Pull requests

Décrivez clairement :

- le problème corrigé ;
- les fichiers modifiés ;
- les tests réalisés ;
- les éventuelles limites de compatibilité.

Les contributions sont distribuées sous GPL-3.0-or-later lorsqu'elles sont intégrées au projet.

## Traductions et glossaires

Les règles linguistiques génériques sont bienvenues. N'ajoutez pas une traduction complète ou des dialogues extraits d'un fangame tiers sans autorisation explicite.
