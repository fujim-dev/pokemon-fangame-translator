# Pokémon Fangame Translator v1.0.2 — Bêta publique

Cette version prépare la première publication publique : interface débutant, traduction hors ligne, relecture intelligente, diagnostics respectueux du contenu du jeu et reconstruction dans une copie séparée.

## Compatibilité annoncée

Certains fangames RPG Maker XP / Pokémon Essentials avec dossiers `Data` et `PBS` accessibles. Compatibilité particulièrement testée avec Pokémon Myth 2. Il ne s'agit pas d'une compatibilité universelle.

## Téléchargement conseillé

`Pokemon_Fangame_Translator_Setup_v1.0.2.exe`

Vérifiez l'empreinte dans `SHA256.txt`. L'installateur n'est pas encore signé numériquement ; Windows SmartScreen peut afficher un avertissement.
