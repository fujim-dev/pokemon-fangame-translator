# Code de conduite

Nous souhaitons une communauté accueillante, constructive et respectueuse.

## Comportements attendus

- Respecter les autres membres et leurs niveaux techniques.
- Critiquer les idées et le code, jamais les personnes.
- Expliquer clairement les problèmes et les tests réalisés.
- Protéger la vie privée et les fichiers appartenant aux créateurs de fangames.

## Comportements interdits

- Harcèlement, insultes, menaces ou discriminations.
- Spam, arnaques, liens dangereux ou publicité non autorisée.
- Publication de fangames complets, ROM, fichiers Data, dialogues extraits ou ressources protégées.
- Publication de données personnelles, secrets, mots de passe ou jetons d'accès.

## Application

Les mainteneurs peuvent modifier ou supprimer un contenu et limiter l'accès d'une personne qui ne respecte pas ces règles. Les problèmes sensibles doivent être signalés de manière privée conformément à `SECURITY.md`.
